# Catalogue source

Cette liste compte **899 entrées** et reprend la dernière édition de RETROID // THE ARCHIVE (11 novembre 2026). Les identifiants historiques restent stables.

- Source : `catalogue_ultimate.csv`, au format CSV UTF-8 avec en-tête.
- Champs : `id, title, platform, genre, priority, grade, source, editorial_bucket, reason, device, run_target, notes, patch_base, official_link`.
- Les libellés de plateformes composites (ex. GBA · ROM hack) sont des indications éditoriales et **ne sont pas** des noms de dossier ES-DE.
- Aucun Pokémon officiel ; les ROM hacks et fangames sont conservés.
- Sept jeux dans la famille course/sport.
- `run_target` signale une méthode envisagée, non un test de performance.

Ne change pas un identifiant déjà employé dans les favoris et exports de progression. Pour vérifier : `python scripts/validate_catalogue.py`.
