# ROM hacks, mods et fangames

Un **ROM hack** est généralement un patch IPS/BPS/UPS/xdelta appliqué à un fichier de jeu de base compatible. N'ajoute pas le jeu de base ou le fichier patché à GitHub sans avoir les droits de distribution.

Procédure :

1. Trouver la page de l'auteur ou du projet ; vérifier la version actuelle et le statut.
2. Obtenir le patch redistribuable depuis sa source officielle ; consulter sa licence.
3. Vérifier la région, la révision et si possible le SHA-256 du jeu de base légalement détenu.
4. Appliquer le patch localement avec l'outil indiqué par l'auteur.
5. Tester le résultat dans l'émulateur et consigner la version du patch.

Les fangames PC (RPG Maker, jeux Windows, etc.) **ne sont pas des ROMs** et ne fonctionneront pas automatiquement sur Android. Un port Android peut exister ; il doit être testé et vérifié. Ne pas supposer qu'un jeu PC personnel est accessible via GeForce NOW.

Le catalogue source répertorie les créations de fans et les liens connus ; aucune ROM, aucun patch non autorisé ni fichier protégé n'est inclus.
