# Trophées et progression

Deux sources **distinctes** :

- **RetroAchievements :** vrais succès pris en charge uniquement par les jeux et les émulateurs/cores compatibles. Connexion et activation à effectuer dans chaque application appropriée. Site : https://retroachievements.org/.
- **Suivi personnel :** favoris, backlog, terminés et objectifs éditoriaux enregistrés dans le navigateur par l'interface HTML. Ce n'est pas un système de succès validés par l'émulateur.

Ne jamais fusionner des trophées personnels avec des trophées RetroAchievements en leur donnant une provenance officielle. Sauvegarder régulièrement l'export JSON du navigateur dans un dossier **local privé**, jamais sur un dépôt GitHub public.

Les succès Switch 2 et cloud PC n'ont pas de synchronisation universelle avec RetroAchievements.
